# QA Automation Challenge

## Overview

This repository contains my solution for the QA Automation Challenge.

## Tech Stack

- Python
- Playwright
- Pytest
- Requests
- pytest-html

## Project Structure

(config, pages, tests, utils...)

## Features

- Login Automation
- Invalid Login Validation
- Add Product to Cart
- Logout
- API Testing
- HTML Reporting

## Installation

pip install -r requirements.txt

python -m playwright install

## Run Tests

python -m pytest

## Generate HTML Report

python -m pytest --html=reports/report.html --self-contained-html
